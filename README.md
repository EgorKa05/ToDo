# ToDo
Приложение **To-Do List** на чистом HTML/CSS/JavaScript.

## Что реализовано в To-Do
- Добавление задачи кнопкой и клавишей `Enter`.
- Валидация: нельзя добавить пустую задачу.
- Редактирование задачи (кнопка **Редактировать** → поле ввода → **Сохранить**).
- Удаление задачи.
- Отметка выполнения через чекбокс (с визуальным `line-through`).
- Сохранение задач в `localStorage` после каждого изменения.
- Восстановление задач из `localStorage` при открытии страницы.
- Фильтры задач: **Все / Активные / Выполненные**.
- Счётчик оставшихся задач и кнопка **Очистить выполненные**.

## Дополнительные функции
- Ограничение длины задачи: 100 символов.
- Приоритеты задач: высокий / средний / низкий + цветовая подсветка.
- Drag and drop для изменения порядка задач.
